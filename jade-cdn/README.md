Jade-CDN
=====================

基本使用
---------------------

登录服务器，执行``bash scripts/deploy-cdn.sh：

```bash
cd /home/nginx/jadecdn/
rm -rf webroot
tar -xvf cdn.tar.gz
rm cdn.tar.gz
```
